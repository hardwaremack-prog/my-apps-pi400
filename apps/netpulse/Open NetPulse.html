NetPulse

Looking for NetPulse...

NetPulse is a small program that does the pinging, so it has to be started first.

  1. Double-click the NetPulse icon on the Desktop (it's added by Set Up My Apps.sh). Or find it in the Raspberry Pi menu under Internet.
  2. Keep the black window that opens. The dashboard opens by itself.

No icon? Open a Terminal and type:
python3 ~/Desktop/"My Apps"/apps/netpulse/netpulse.py

This page keeps checking and jumps to NetPulse as soon as it's running.
