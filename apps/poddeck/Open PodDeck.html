PodDeck

Looking for PodDeck...

PodDeck is the control panel for Podman containers. It's a small program that has to be running first.

  1. Double-click the PodDeck icon on the Desktop (added by Set Up My Apps.sh), or find it in the Raspberry Pi menu under System Tools.
  2. The first time, it installs Podman and asks you to pick a password. After that it starts by itself every time the Pi boots.

No icon? Open a Terminal and type:
bash ~/Desktop/"My Apps"/apps/poddeck/install.sh

PodDeck is for the Raspberry Pi (64-bit Raspberry Pi OS). It doesn't run on Windows.

This page keeps checking and jumps to PodDeck as soon as it's running.
