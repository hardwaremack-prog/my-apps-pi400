Real DOS session (js-dos / DOSBox-WASM)

This must be run from a local web server, not by double-clicking the file. Browsers block WebAssembly + worker loading over file://. From this folder run:
python3 -m http.server 8080 (or npx serve)
then open http://localhost:8080/real-dos-jsdos.html.
What's actually booting here: by default (no bundle URL set below) js-dos starts its own built-in DOSBox shell — a real, DOS-compatible command interpreter (Z:\> prompt), not literally FreeDOS or PC DOS. It's genuinely DOS-compatible (runs real 16-bit .EXE/.COM files, real SmartDrive/QuickMenu/GW-BASIC binaries if you supply them) but it isn't a full installed OS image.

To boot an actual FreeDOS (or PC DOS) disk image instead:
  1. Go to dos.zone and use their "Game Studio" / bundle search for a FreeDOS boot disk bundle (search "FreeDOS"). Grab the .jsdos URL it gives you.
  2. Paste that URL into the BUNDLE_URL constant below, replacing null.
  3. Reload the page — js-dos will boot that image instead of the built-in shell.
To add QuickMenu / SmartDrive / GW-BASIC yourself: once the shell is running, use the js-dos on-screen menu (gear/upload icon in the player UI) to drag and drop real DOS-era files you legally own onto the C: drive, then run them normally (SMARTDRV.EXE, QUICKMENU.EXE, GWBASIC.EXE). I can't fetch or bundle those binaries myself — they're commercial/copyrighted software, same as MS-DOS or PC DOS itself.
