Looking for PiDirStat...

PiDirStat is a small program that does the scanning, so it has to be started first.

  1. Double-click the PiDirStat icon on the Desktop (it's added by Set Up My Apps.sh), or find it in the Raspberry Pi menu under System Tools.
  2. Keep the black window that opens. The viewer opens by itself when the scan is done.

No icon? Open a Terminal and type:
python3 ~/Desktop/"My Apps"/apps/pidirstat/pidirstat.py / --open

On Windows, double-click Start PiDirStat (Windows).bat in this folder instead.

This page keeps checking and jumps to PiDirStat as soon as it's running.
