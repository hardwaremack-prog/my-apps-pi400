Looking for PON Lab...

PON Lab is a small program that runs the relays, so it has to be started first.

  1. Just trying it? Double-click the PON Lab (simulation) icon on the Desktop (added by Set Up My Apps.sh). No relays needed. On Windows, double-click Try PON Lab (simulation).bat in this folder.
  2. Real test bench? On the Pi wired to the relays, run sudo ./install.sh in this folder once. It starts by itself on every boot.
