Looking for PiMesh...

PiMesh runs in the background on each Pi, so it has to be started first.

  1. Set it up on a Pi: run sudo ./install.sh in this folder once on every Pi. They find each other automatically and it starts on every boot.
  2. Just looking? Double-click the PiMesh (demo) icon on the Pi Desktop, or Try PiMesh (demo).bat on Windows. It shows 6 pretend Pis.
