Blueprint Wiki

Looking for Blueprint Wiki...

Blueprint Wiki is a small program that keeps your pages, diagrams and files, so it has to be started first.

  1. Double-click the Blueprint Wiki icon on the Desktop (it's added by Set Up My Apps.sh), or find it in the Raspberry Pi menu under Office.
  2. It runs quietly in the background. Leave it running while you use the wiki.

No icon? Open a Terminal and type:
bash ~/Desktop/"My Apps"/apps/blueprint-wiki/start.sh

On Windows, double-click Start Blueprint Wiki (Windows).bat in this folder instead.

This page keeps checking and jumps to Blueprint Wiki as soon as it's running.
