THE HAM RADIO MUSEUM
====================
Amateur radio from the 1930s boatanchors to today's SDRs: 50 rigs with
common issues, upgrades and prices, the best value radios you can buy
today with starter-station totals, US band plan, antenna picker and wire
calculator, amplifiers, shack software and Pi digital station, WebSDR
links, and an offline toolkit (Morse player, SWR, grid square, coax loss).

Open "Ham Radio Museum.html" in any web browser. Works offline.
