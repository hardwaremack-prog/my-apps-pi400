Did You Knowreference

What this measures: "Core Infrastructure" polls the public status APIs that Cloudflare, GitHub, Google Cloud and other providers publish about their own systems — real incident data, not a simulation. "DNS Resolvers" and "Regional Edge Reachability" time live requests sent directly from your browser, so they describe internet health as experienced from your current connection, not a globally distributed probe network. "Global Traffic-Hour Context" is computed from real local time in each region using a simple 7am–11pm heuristic for "peak," meant as context, not a traffic measurement.

Limits: browsers can't send raw ICMP pings or run probes from other continents, so a "down" regional tile can mean the endpoint is actually down, or that something on your local path (firewall, ISP routing, CORS policy) is blocking the request — both are real signals, just different ones. The "Did You Know" panel is static reference trivia about internet infrastructure, not a live measurement. Auto-sweeps every 15s.
