This boots a real Linux kernel (Buildroot) inside a real x86 CPU emulator (v86, WebAssembly JIT) running entirely client-side, with a real busybox shell attached over the emulated serial console — it is not a scripted animation. It needs to fetch the kernel image (a few MB) over the network the first time, so boot can take 15–60s. Once the shell is ready, a real busybox-based control panel script gets typed onto the live filesystem and launched automatically — no fake GUI, just real commands wrapped in a menu. Type 10 then Enter to drop to the raw shell, and menu to come back, or hit the Menu button. You can also drag and drop files onto the screen — they're written into a real virtio-9p share and appear inside the VM at /mnt/. If this sandbox blocks the cross-origin fetch, download this file and open it directly in a browser tab and it'll boot the same way.
