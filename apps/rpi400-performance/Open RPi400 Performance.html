RPi400 Performance

Starting RPi400 Performance…

It's a small program, so it has to be running first.

  1. Double-click the RPi400 Performance icon on the Desktop (added by Set Up My Apps.sh), or find it in the Raspberry Pi menu under Preferences.
  2. It opens in its own window.

No icon? Open a Terminal and type:
python3 ~/Desktop/"My Apps"/apps/rpi400-performance/rpi400perf.py

This page keeps checking and jumps to it as soon as it's running.
