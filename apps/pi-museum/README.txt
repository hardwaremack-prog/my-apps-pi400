THE RASPBERRY PI MUSEUM
=======================
Every Raspberry Pi board, from the 2012 Model B to the Pi 500+ and the Picos:
specs, hacks, known issues, power and cooling, an overclocking table, a model
compare, speed and AI (tokens per second) labs, a "which Pi is this?" decoder,
a GPIO pin map and copy-paste fixes.

Open "Raspberry Pi Museum.html" in any web browser. Works offline.
