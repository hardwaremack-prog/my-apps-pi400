Everyone spawns with a different weapon — kill someone and you take theirs. Med-kits, weapon crates, speed, shields, and cloaking devices spawn around the mall. Hostile alien species patrol the halls. Other operators sync in every ~1s. Enter a party code to play a private match with just your friends — anyone with the same code (on your network or anywhere else) joins your instance instead of the public one. Running on weaker hardware? Check "low-power mode" above — it drops render resolution, turns off antialiasing, and only keeps nearby lights active, trading a bit of visual polish for real framerate.

Power-Ups

Med-Kit — restores 40 health.
Weapon Crate — swaps you to a random weapon.
Adrenaline — 1.6x move speed for 8 seconds.
Shield Cell — adds 50 shield, absorbs damage before health.
Cloak — turns you nearly invisible and hides you from bots for 8 seconds.
Pizza slice (Starlite Pizza Cafe) — +25 health, or +5 per pizza off the conveyor belt.
Cola / Mountain Dew (Starlite Pizza Cafe) — same speed boost as Adrenaline.

Multiplayer

This runs as synced cloud storage, not a dedicated server — other players' positions, health, and shots update roughly once a second, so treat it as tactical delay, not a live feed. The game also tries to upgrade each connection to a direct peer-to-peer link behind the scenes (WebRTC) — when that succeeds you'll see "P2P" next to the online count, and that specific player's movement becomes much smoother and near-instant. If a direct link can't be established (some networks block it), that player just keeps working over the slower synced storage automatically — nothing breaks either way. Leave the party code blank to land in the shared public arena with anyone else currently playing. Enter a code to create a private instance — share that exact code with friends and you'll only see each other, on the same network or anywhere else. AI bots are simulated locally, so everyone gets their own bot squad regardless of party. Press T in-game to open text chat and leave a message for anyone else in your arena — it syncs the same way, so give it a couple seconds to show up on their screen.
